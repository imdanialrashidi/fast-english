# Vazirmatn — self-hosted font

This directory contains the official Vazirmatn variable WOFF2 font and its
SIL Open Font License (OFL 1.1) attribution file.

- Source: https://github.com/rastikerdar/vazirmatn
- Release: v33.003
- File: `Vazirmatn-VF.woff2` (single variable font, weight axis 100–900)
- License: `OFL.txt` (SIL Open Font License 1.1)

The font is loaded via `@font-face` declared in `app/src/styles.css`.
No runtime font CDN is used.
