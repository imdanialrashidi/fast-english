| محیط | آدرس |

**قانون:** اگر در نوار آدرس `admin.fastenglishpodcast.com` نیست → محیط تست است.

## رایج‌ترین کارها

1. **ورود:** ایمیل + رمز → «ورود مدیریت» → «داشبورد مدیریت»
2. **صف پرداخت‌ها:** «پرداخت‌ها» → فیلتر «در انتظار بررسی» → کلیک روی درخواست
   (پیش‌فرض صف «همهٔ درخواست‌ها» است؛ درخواست‌های «در انتظار» اول می‌آیند)
3. **بررسی رسید:** بزرگ‌نمایی رسید → چک SOP: خوانایی، مبلغ = مبلغ مورد انتظار، کارت مقصد، زمان، فرستنده
4. **تأیید:** دکمهٔ «تأیید» → تأیید نهایی (اختیاری: یادداشت داخلی)
5. **رد:** دکمهٔ «رد» → «دلیل رد» (≥۳ حرف؛ برای دانشجو نمایش داده می‌شود) → تأیید نهایی
6. **جستجوی صف:** مرجع بانکی یا شناسهٔ درخواست (نه نام/شماره)
7. **خروج:** دکمهٔ قرمز «خروج» در نوار بالا

## معنی وضعیت‌ها

| وضعیت | برچسب | یعنی |
|---|---|---|
| درخواست: `pending` | در انتظار | رسید ثبت شده؛ منتظر بررسی شماست |
| درخواست: `approved` | تأیید شده | اشتراک فعال شد |
| درخواست: `rejected` | رد شده | با دلیل ثبت شد؛ کاربر می‌تواند رسید جدید بفرستد |
| درخواست: `cancelled` | لغو شده | کنار گذاشته شده؛ معمولاً اقدامی لازم نیست |
| حساب: `pending_payment` | در انتظار پرداخت | تازه ثبت‌نام کرده |
| حساب: `payment_rejected` | پرداخت رد شده | آخرین رسید رد شده و اشتراک فعالی ندارد |
| حساب: `active` | فعال | اشتراک فعال دارد |
| حساب: `expired` | منقضی شده | اشتراک تمام شده |
| حساب: `suspended` | معلق | دسترسی قطع شده → ارجاع به مالک/مسئول فنی |
| اشتراک | فعال / منقضی شده | دورهٔ دسترسی |
| محتوا | پیش‌نویس / منتشر شده / آرشیو شده | وضعیت اپیزود و نسخهٔ سطح |

## هشدارهای حیاتی

- ❌ **هرگز** رکوردهای دیتابیس را دستی تغییر ندهید.
- ❌ **هرگز** رمز سوپریوزر را نخواهید، ندهید، نگه ندارید — اپراتور به آن نیاز ندارد.
- ❌ **هرگز** در محیط تولید دادهٔ تست/دمو وارد نکنید (کارت ساختگی، قیمت آزمایشی، بانک سؤال دمو).
- ❌ رد کردن، «بازگردانی تأیید» نیست. تأیید اشتباهی → اطلاع به مالک (مسیر اصلاح با او).
- ❌ بازیابی رمز خودکار وجود ندارد → ارجاع به مسئول فنی.
- ❌ وعدهٔ زمان پاسخ خارج از «حداکثر تا ۲۴ ساعت» (یا متن SLA تنظیمات) ندهید.
- ⚠️ تصویر رسید به تنهایی اثبات پرداخت نیست؛ طبق SOP بررسی کنید.
- ⚠️ اطلاعات دانشجویان (نام/موبایل/رسید) خصوصی است.
- ✅ سطح CEFR مرز دسترسی نیست؛ تعیین سطح فقط «پیشنهاد» است.

## قوانین ارجاع (خلاصه)

| اگر این را دیدی | اقدام |
|---|---|
| یک کاربر نمی‌تواند وارد شود | وضعیت حساب را ببین (معلق؟ رد؟) → اگر عادی ولی خطا → فنی |
| صوت فقط یک اپیزود خراب است | بررسی محتوا → اگر محتوا سالم، پخش کلی خراب است → فنی |
| سایت برای همه در دسترس نیست / خطای ۵۰۲ | **ارجاع فنی فوری** |
| شک به نفوذ/نشت | **ارجاع امنیتی فوری** (مالک + مسئول فنی) |
| درخواست بازگشت وجه / تأیید اشتباهی | ارجاع به مالک |
| تعیین سطح دوباره / اصلاح سؤال | ارجاع به مالک (در محصول فعلی ممکن نیست) |

هرگز سرور را ری‌استارت نکنید، مهاجرت اجرا نکنید یا رمزی افشا نکنید (مگر مسئول فنی باشید).

## چک‌لیست روزانه

- [ ] ورود → «داشبورد»: شمار در انتظارها
- [ ] «پرداخت‌ها» ← بررسی همهٔ در انتظارها (SOP) → تأیید/رد با دلیل
- [ ] پاسخ پشتیبانی (الگوهای بخش ۱۲ راهنمای کامل)
- [ ] بررسی وضعیت حساب کاربرانِ دارای مشکل
- [ ] محتوا (اگر وظیفهٔ شماست): پیش‌نویس‌های آماده
- [ ] سلامت: `app.fastenglishpodcast.com` و لندینگ باز می‌شوند؟
- [ ] ثبت مشکلات غیرقابل‌حل + «خروج» امن

## انتشار محتوا (خلاصه)

1. «محتوا» → «اپیزود جدید» (عنوان فارسی، slug، دسته‌بندی، توضیح، شماره)
2. «تصاویر»: تصویر مربع (≤۵MB) + (اختیاری) تصویر عریض
3. «نسخه‌های سطح»: برای هر سطح → نسخه بسازید (خلاصه/صوت/متن/واژگان)
4. صوت: MP3/M4A ≤۱۰MB؛ مدت خودکار خوانده می‌شود
5. واژگان: واژه + معنی فارسی + توضیح انگلیسی (الزامی)
6. «پیش‌نمایش» را ببینید؛ پنل «آماده انتشار» خطای مانع نداشته باشد
7. «انتشار اپیزود» / «انتشار نسخه» → بلافاصله برای دانشجویان فعال دیده می‌شود

**ورود بسته:** «ورود محتوا» ← ZIP ← «بررسی» ← «برنامه ورود» ← «تأیید و ورود محتوا» — همیشه پیش‌نویس؛ هرگز اعتبارسنجی را دور نزنید.

## یادآوری نهایی

مشکلی مبهم بود؟ **ارجاع دهید، خودسرانه عمل نکنید.** مسیر: اپراتور ارشد → مالک → مسئول فنی.
