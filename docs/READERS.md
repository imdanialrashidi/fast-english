# Reading tracks — story books, Cambridge IELTS, Inside Reading

Owner decisions 2026-11-21. This document is the owning contract for the
three reading tracks and the shelf they live on. The coursebook track
(American English File) keeps its existing contract in `docs/PRODUCT.md`.

## 1. Owner decisions (locked)

### Shelf

- `/app/books` is a four-item shelf: **کتاب** (the existing six American
  English File coursebooks), **استوری‌بوک**, **کمبریج آیلتس**, **اینساید ریدینگ**.
- The tab row above every books screen is a URL, not client state:
  `همه / کتاب / استوری‌بوک / آیلتس / اینساید ریدینگ`.
- The bottom navigation keeps five destinations; the reading tracks live
  under «کتاب‌ها».

### Story books (Oxford Bookworms)

- Levels: **Starter → A2**, **Stage 1 → B1**, **Stage 2 → B2**,
  **Stage 3 → C1**, **Stage 4 → C2**.
- One 2×3 art sheet per book, generated by the owner; the app crops one
  panel per page with CSS. A page without a panel gets no image and never
  inherits the previous picture.
- Image first on the page; the collapsed «پیش‌خوانی» pill sits above it.
- Audio is the original narration file and must be synchronised with the
  page text. Highlight is real-time sentence level, warm amber, never a
  saturated yellow.
- **0–5** hard words per page, chosen only when the page has a genuinely
  useful word at the book's band + the next band (A2+B1, B1+B2, B2+C1,
  C1+C2, C2+C1). **Zero is valid**; never pad a page to hit five. Words
  and Persian meanings sit above the image; the collapsed «پیش‌خوانی»
  pill must still work with an empty list.

### Cambridge IELTS

- Books 19 (Academic + General), 20 (Academic), 21 (Academic).
- Academic: Reading → Test 1–4 → Passage 1–3. General: Reading → Test 1–4
  → Section 1–3 (the real IELTS structure).
- Every paragraph is taught before it is read: B2+ and technical words
  first, with pronunciation and a repeat, then a simple English meaning;
  then the paragraph at normal speed with a sentence highlight.
- The reading questions use their real types and are answerable in place.
  «دیدن کل ریدینگ» is always available. Selecting text shows a Persian
  translation.
- The AI extracts the passage, questions and the back-of-book answer key.
  A wrong answer can show the exact evidence sentence highlighted plus a
  Persian explanation of why the correct answer is correct.
- IELTS has no supplied audio: the teaching voice is Underdog Woof. The
  app shows «Voice by Underdog Woof» wherever that audio is used.

### Inside Reading

- Five levels: Intro, 1, 2, 3, 4. Ten units, two readings each.
- Intro and 1: B1+ words with Persian meaning, at most **10 per
  paragraph**. Levels 2–4: B2+ words with a short, simple English
  definition; a simple synonym when one is enough (`intelligent means
  smart`); Persian for a genuinely complex word.
- Every blue/underlined word in the text has a definition or synonym at
  the head of its paragraph.
- Original book audio; no TTS. Image first, word preview, text highlight.

```text

/app/books/ielts/{year}/{variant}/test-{n}
/app/books/ielts/{year}/{variant}/test-{n}/passage-{n}
/app/books/inside-reading           level list
/app/books/inside-reading/{level}   unit list

/app/books/inside-reading/{level}/unit-{n}/reading-{n}
```

`{track}` is URL-friendly (`inside-reading`) and maps to the database key
`inside_reading`. Every node has one stable slug that starts with its
track; the path below the track never depends on the parent title. Legacy
AEF URLs (`/app/books/{book}`, `/app/books/{book}/{unit}`) stay valid.

## 3. Data model

| Table | Role |
|---|---|
| `library_nodes` | Navigation tree: series, level, book, variant, test, passage, unit, reading. Title, level, cover, order, status, meta. |
| `reading_documents` | One versioned JSON document per readable leaf. Counts, checksum, publish timestamp. |
| `reading_progress` | Owner × node: page key, real audio position, content revision, completion. |
| `reading_attempts` | IELTS submissions: raw answers, score, total. |

A leaf is readable only when its document exists **and** is published
**and** the node status is `published`. A parent node with visible children
is a navigable container; a leaf without a document is an honest
«در حال آماده‌سازی» page, never fake content.

### Document shape

Story / Inside Reading:

```json
{
  "schema_version": "1.0",
  "meta": {"kind": "story", "level_cefr": "A2", "band": ["A2", "B1"],
           "sheet": {"file": "sheet.webp", "columns": 2, "rows": 3}},
  "chapters": [{
    "id": "ch1", "title_en": "Chapter 1",
    "audio": {"file": "ch1.mp3", "duration_ms": 285679},
    "pages": [{
      "id": "p1", "number": 1, "text_en": "...", "panel_index": 1,
      "alt_fa": "...", "audio": {"start_ms": 0, "end_ms": 18000},
      "words": [{"word": "jogger", "meaning_fa": "دونده",
                 "start_utf16": 0, "end_utf16": 6,
                 "audio": {"file": "w-001.mp3"}}],
      "sentences": [{"start_utf16": 0, "end_utf16": 20,
                     "start_ms": 0, "end_ms": 3000, "text_fa": null}]
    }]
  }]
}
```

IELTS:

```json
{
  "schema_version": "1.0",
  "meta": {"kind": "ielts", "credit": "Voice by Underdog Woof"},
  "passage": {"title_en": "...", "paragraphs": [{
    "id": "A", "label": "A", "text_en": "...", "audio": {"file": "pA.mp3"},
    "words": [{"word": "mature", "definition_en": "fully grown",
               "meaning_fa": "بالغ", "start_utf16": 22, "end_utf16": 28}],
    "sentences": [{"start_utf16": 0, "end_utf16": 30,
                   "start_ms": 0, "end_ms": 4200, "text_fa": "..."}]
  }]},
  "questions": [{
    "id": "q1", "number": 1, "type": "tfng", "prompt": "...",
    "options": [], "answer": "TRUE", "accepted": ["TRUE"],
    "explanation_fa": "...", "why_wrong_fa": "...",
    "evidence": {"page_key": "A", "start_utf16": 20, "end_utf16": 48}
  }]
}
```

Question types supported by the current grader: `choice`, `multi_choice`,
`tfng`, `ynng`, `completion`, `short_answer`. Answers accept a normalised
string or a set; completion accepts `answer` plus `accepted` alternatives.
Every offset is **UTF-16** and inside its own text; sentences are monotonic.

## 4. Content pack and import

A pack is a directory outside the repository:

```text
pack/
  pack.json          # schema_version, track, node, document
  audio/             # chapter/paragraph/word mp3s referenced by filename
  images/            # sheet and any pre-cropped page images
```

Commands (inside the app container):

```sh
php artisan library:catalog                  # idempotent shelf skeleton
php artisan library:import <pack> --publish  # validate → copy → store → publish
```

The importer:

1. validates the tree, text, UTF-16 spans, audio/image references and IELTS
   questions (`ReadingPackValidator`);
2. copies assets to `storage/app/private/library/{slug}/r{revision}/`;
3. stores the document with a SHA-256 checksum and a new revision;
4. writes counts and duration into the node meta;
5. publishes only with `--publish`; otherwise the document is staged and the
   leaf stays «در حال آماده‌سازی».

A failed validation writes nothing. A bad offset, a missing audio file or a
question without a key is a hard stop, not a warning. Re-running
`library:catalog` after an import only moves/levels the node; it never resets
the title, cover, status or counts of a node that already owns a document.

## 5. Reader contracts

- **Offsets.** All highlight/word/evidence offsets are UTF-16 code units.
  JavaScript slices the text directly; PHP validates with `Utf16` and never
  re-encodes the text. No byte-offset slicing.
- **Highlight.** The active sentence is computed from the real playback
  clock (`timeupdate`), not a timer. In the silence between sentences no
  sentence is active. A missing sync leaves the highlight off; the audio
  still plays.
- **Resume.** Progress stores the node, page key, millisecond position and
  document revision. A changed revision starts the page again; a missing
  page falls back to the first page.
- **Word preview.** The pill is optional and collapsed by default. Opening
  it never pauses the narration. IELTS pre-teaches the paragraph words
  before the paragraph audio, with a per-word repeat.
- **IELTS grading.** The page payload never contains `answer`,
  `explanation_fa` or `evidence`; `POST /app/library/{node}/attempts`
  grades on the server, stores the attempt and returns the explanation.
  The «نمایش شاهد» action opens the full reading and highlights the stored
  span.
- **Translation.** IELTS sentence translations are precomputed in the pack.
  A text selection maps to the intersecting sentences (and any selected
  glossed words) and shows their Persian text; no runtime translation call.
- **Media.** Audio is `private, no-store` with Range support. Page art is
  private and cached immutably by revision. The raw PDF is never served.
