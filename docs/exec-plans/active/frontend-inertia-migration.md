## 1. Goal and explicit non-goals

Goal: migrate the public and learner-facing UI of the existing Fast English checkout (Laravel 13 + PostgreSQL + Filament staff panel) to Inertia 3 + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui, keeping every route/URL, domain model, migration, policy, money/time rule, private media delivery, and operational boundary intact, with one permanent light theme in the exact owner-approved palette and Filament kept for staff.

Non-goals: database replacement; Laravel regeneration; discarding functionality; fresh starter kit over the repository; second/parallel learner frontend; bank gateway/OCR/SMS/push/AI/TTS/word-level/gamification/recommender/coupons/multi-teacher/multi-locale additions; dark/system/sepia themes; new invented palette; production deploy/merge/release; weakening any auth/money test to obtain green.

## 3. Confirmed facts, constraints, assumptions, and material unknowns

Facts (from this checkout): Laravel 13 (`laravel/framework ^13.17`, platform PHP 8.4.26) + PostgreSQL + Vite + Tailwind 4 (`@tailwindcss/vite`, `tailwindcss ^4`) + Livewire 4.4 + Fortify 1.41 + Filament 5; 43 Blade views across public/auth/learner/layouts; one learner Livewire component (`UpdateDisplayName`); 44 `wire:navigate` usages; single `@persist('fe-player')` audio + `reader-player.js` (1006 lines) + `theme.js` (system/light/dark + `fe-theme`) + pre-paint scripts in 3 layouts; Fortify session auth with `disabled_at` + login throttle; controllers return Blade today; file routes serve private bytes with Range + `private, no-store`; SW allowlist avoids private data; scope §2 foresees the Inertia+React registered change for `shadcn/ui`.
Constraints: one Laravel app / one DB / one origin; no parallel REST API or Node API; no fresh-starter-kit overwrite; Filament Livewire stays but never leaks into learner bundle; single light theme; exact palette only; per-slice parity before deleting obsolete learner code.
Assumptions (reversible): route paths/URLs stay identical; JSON mutation endpoints (progress/bookmarks/words/placement-answers/receipt-upload) keep shapes and become Inertia/form posts; Vite gains TS/React inputs without changing the PHP runtime.
Material unknowns (build agent must resolve against version-matched official docs, not assumed here): exact Inertia 3 adapter/server-package versions compatible with Laravel 13 + React 19 + Livewire-4-inside-Filament coexistence; React 19 + TS + shadcn/ui component set and Tailwind v4 theme-variable mapping; file-upload transport detail; persistent-layout/scroll-restoration specifics. Missing vision/browser capacity at build time leaves pixel criteria UNPROVEN, never passed.

## 5. Smallest viable design and relevant data/control flow

Transport swap only: controllers keep authorization/validation and return `Inertia::render(<Page>, <allowlisted props>)` instead of Blade; React pages (TS + shadcn/ui on Tailwind v4 theme variables mapped 1:1 from the light tokens) replace Blade views; mutations POST to the same endpoints with CSRF session auth and server error bags; file/media bytes stay classic controller responses (never Inertia props); a React persistent layout owns the single `HTMLAudioElement` (replacing `@persist` + `wire:navigate` persistence); level/filter/search state stays in the URL (`?level=`, pagination, filters); `preferred_level`/`recommended_level`/goal/SRS/cues/plan ownership unchanged; Filament routes/views untouched.

## 6. Security, correctness, performance, UX, migration, reliability, recovery, and rollback risks (only where relevant)

- Security: prop leakage (premium body/glossary/audio URLs, answer keys, `correct_option`/`scoring_rules`, receipt paths/bank refs, secrets) into Inertia props — port absence assertions; CSRF 419/session-expiry/disabled-account/rate-limit parity; staff self-approval ban + `canAccessPanel`; `private, no-store` + SW network-only re-audit.
- Correctness: level substitution, cross-user/lesson/revision mixing, fake-saved progress, double-apply money effects — existing isolation/idempotency/race tests must stay green.
- Performance: N+1 on library props, audio `preload=metadata`, no admin assets in learner bundle, bundle-size watch on React addition.
- UX/migration: player duplication/lost playback on Inertia navigation; back/forward + scroll restoration; file-input/upload UX; RTL/FA + LTR/EN islands, Vazirmatn/Inter loading, 200% zoom, 320 reflow, 44px targets, visible focus, `prefers-reduced-motion`; contrast re-measured on exact light pairs only.
- Reliability/recovery/rollback: obsolete code deleted only after parity (git history is the rollback); migrations never reversed blindly; money/history rows never cascade-deleted; backup/restore drill unaffected (no schema change in migration).
